The goal is a queue whose next item can be picked up and worked without a question
being asked first. Work over the issues already on the board: judge each against what
the operation is for, and change the board so that judgment is legible to whoever
reads it next.

For each issue you touch, decide and record:
- whether it states an outcome someone could demonstrate, and rewrite it when it does
  not;
- whether it is blocked, and by what — as a tracker relation, never as prose;
- whether it belongs in the queue at all, and move it out when it does not.

Move an issue to queue:proposed only with its blockers recorded and its
outcome stated. Never set queue:approved: approval is a human act. An
open question you cannot settle from the board or the repository is recorded on the
issue that owns it under queue:decision, with the reading you would
proceed under.

Ground every claim you write in something you read. A claim you did not verify does
not go on the board.

Window. Establish what this pass covers before you read the board. The
tracker checkpoint (example-checkpoint-document-id) carries the marker the last
completed pass left, and the timestamp on its most recent entry is where this window
starts. A checkpoint with no entry means no pass has completed yet — cover the whole
board once as a bootstrap census, and say so in your report.

Store. This operation keeps a private store beside the tracker, and what
lives at which destination is stated in the map this session is preluded with. Read from
it before re-deciding something an earlier pass settled, and write what a later pass will
need to the destination that holds that kind of content. Nothing read there reaches a
public surface.

Record. When the work is done, write this pass's own row in
Example Run Log, the knowledge destination example-run-log-destination-id: this pass's start
time, what you examined, what you changed, and what you could not do and why. The runner
records that this pass ran; your row is the prose beside it, written after the work rather
than before it — and a pass that changed nothing writes one too, because a gap in the
record cannot be told apart from a pass that never ran.

Ultrathink. Deeper reasoning is requested for this work — reason as thoroughly
as the task warrants before you act.
