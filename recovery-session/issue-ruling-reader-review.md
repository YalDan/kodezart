Existing read_all(issue_key,lane_key) delegates to the same implementation and retains exact selection behavior. RulingRecordReadError.lane_key is now str|None: None explicitly means issue-wide discovery, never a fabricated lane; existing explicit-lane error messages remain unchanged.
